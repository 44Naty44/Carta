Configuración sin código

Conectar con Google Sheets

El equipo del bar solo edita una planilla de Google; el código en GitHub no vuelve a tocarse.

1. Armá la planilla con estas 6 columnas exactas

En la fila 1 de Google Sheets colocá estos encabezados (en Disponible usá SI o NO):

Categoria | Nombre | Descripcion | Precio | Etiqueta | Disponible
Abrir Google Sheets para crear o editar la planilla

2. Publicá la hoja como CSV

  1. En Google Sheets andá a Archivo → Compartir → Publicar en la web.
  2. En el primer desplegable elegí tu hoja (ej. Hoja 1).
  3. En el segundo desplegable elegí Valores separados por comas (.csv).
  4. Tocá Publicar y copiá el enlace generado.

3. Probador en vivo de tu enlace CSV

Pegá acá el enlace ...pub?output=csv para probar cómo carga la carta ahora mismo. Para dejarlo fijo para todos los clientes, pegalo una única vez en const SHEET_CSV_URL dentro de este archivo.
